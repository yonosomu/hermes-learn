# Inspiration and provenance

This project is an independent, original reimplementation inspired by the feature
concepts of [amosblomqvist/learn](https://github.com/amosblomqvist/learn): teaching
and visualization skills, graded checks, learning logs, and research/diagram roles.
It is not a fork and does not include upstream source, skill wording, prompts,
images, personal configuration or package files. The upstream checkout inspected
for feature mapping had no LICENSE file; its contents are not relicensed here.
“Clean-room” here means original implementation after feature inspection, not a
formal two-team legal clean-room process. No legal clearance is implied.

The MIT license in this repository applies only to this project's original work.
Hermes Agent, Mermaid CLI, librsvg and any viewer are independent projects with
their own licenses. No endorsement by those projects or the inspiration's author
is implied. Public repository ownership: Philip Richard (yonosomu).
