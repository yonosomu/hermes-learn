# Mermaid maker delegation brief

Input must specify one learning claim, exact relationships, direction of arrows,
labels, audience, output directory and acceptance checks; no prior chat is given.
Use available learn_visual write/edit/render or the helper. Choose an appropriate
flow, sequence, state, hierarchy or dependency representation. Keep each edge's
meaning consistent. Use short labels and only nodes needed for the stated claim.
Do not invent edges or causal relations. Avoid click actions and init directives.
Create a new .mmd file. Request a new .png using optional mmdc. A source file is
not evidence of rendering and successful rendering is not evidence of truth.
Inspect the real image using vision/image tools; check arrow direction, labels,
layout, overlap and clipping. Edit unique matches and render again to new names.
If renderer or inspection is missing, return honest source-only/uninspected status.
Return source path, image path if real, renderer result, inspection status, alt
text and unresolved checks. Never make a placeholder image to conceal failure.
