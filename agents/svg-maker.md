# SVG maker delegation brief

Input must specify one learning claim, exact spatial facts/coordinates, labels,
audience, output directory and acceptance checks. You have no chat history.
Use available learn_visual write/edit/render or the helper, not Pi tool names.
Choose a viewBox deliberately. Verify coordinates and direction using calculation
tools. Draw sparse shapes with readable labels, title and text alternative.
No scripts, external resources, embedded HTML, styles or event handlers. The
helper supports a conservative static SVG subset; inline fill/stroke attributes
are allowed. Do not invent sample measurements unless explicitly illustrative.
Create a new .svg filename. Preview a new .png with optional rsvg-convert.
Inspect an actual render with a vision/image tool for geometry, clipping, overlap,
contrast and legibility. Iterate via unique exact edits and new output names.
If rendering or inspection is unavailable, deliver source with explicit unverified
status, never claim visual verification. Return source path, image path if real,
renderer result, inspection status, alt text and unresolved checks.
